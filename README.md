#### ⚙️ Autobot
*Autonomous line-follower & maze-solver — AXIS'26, VNIT Nagpur*

Custom PCB integrating an ESP32, Pololu QTR-8A IR array, TB6612FNG motor driver, and N20 motors. Firmware runs closed-loop PID line-following alongside priority-based maze solving — the bot performs a dry run to map the maze, then replays an optimized shortest path on subsequent runs.

`ESP32` `PID Control` `Custom PCB` `Maze Solving` `Fusion 360`

[**→ View Repo**](https://github.com/manassahu-cmd)

</td>
<td width="50%" valign="top">

#### ⚡ ForgeAI
*Autonomous agentic startup-naming system*

A dual-agent system (Generator + independent Judge) built on the ReAct pattern — researches the market live via Tavily, generates candidate names with Gemini, and scores them for brandability before returning a ranked shortlist. Includes a 3-model fallback cascade for reliability.

`Gemini API` `ReAct Agents` `Tavily` `Streamlit` `Railway`
